# 独立更新器

当前更新器只支持正式 `vX.X.X` CPU 完整包。关闭旧版界面后，运行安装目录中的
`更新.exe`。程序先启动独立临时助手，原窗口退出后由助手完成更新。

助手按最新 `SHA256SUMS.txt` 选择 CPU 包，下载固定版本 ZIP，校验 SHA256、
解压目录结构和包内版本。上述步骤成功前不会改动旧发行文件。

安装会替换 `runtime`、`plans`、`models`、根配置、启动器、更新器及发行说明。
`user-data`、`gui-settings.ini`、`logs` 和其他非发行文件保留。自行修改的 Plan
会随旧发行文件进入备份，不会自动合并到新版。

## 失败恢复

- 同一安装目录只允许一个更新助手执行下载和安装。
- 文件替换前会在 `.update-work/transactions/<编号>/backup` 备份旧内容。
- 安装失败会回滚，恢复记录写在同目录的 `transaction.json`。
- 更新器自身先完整备份，再原子覆盖，避免中断后根目录没有更新器。
- 如果回滚被文件占用阻止，请释放占用后重新运行 `更新.exe`。程序先恢复上次
  更新，提示恢复完成；再次运行才会检查新版。
- 最近一次成功更新的备份保留，下一次成功更新后清理更旧的成功备份。
- 临时助手所在目录不会在运行期间删除；后续更新会清理超过一天且未运行的助手。

详细错误及阶段日志位于 `logs/updater/`。出现失败时不要手动删除
`.update-work`，其中可能保存着恢复旧版必需的文件。

CPU 包下载不依赖 GPU/overlay 资产。更新器不迁移旧 GPU 安装，不兼容旧版
更新协议。更新器不自动启动游戏，也不会关闭其他安装目录的 Aura 或游戏进程。
