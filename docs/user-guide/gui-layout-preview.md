# GUI 布局预览与本机配置

## 配置隔离

本轮布局使用程序根目录中的 `gui-settings-layout-v2.ini`，首次打开按当前明确默认值初始化。它不读取、不导入、不删除旧 `gui-settings.ini` 或旧 GUI 注册表设置，也不会提示迁移。游戏路径、任务顺序和勾选状态、参数、快捷键等需要在新布局内重新设置，之后会持续保存到新配置。

写入失败时显示保存错误，不会回退导入旧配置。设置页主动检测游戏安装路径仍可查询游戏安装记录；这不是旧 GUI 配置迁移。

旧、新两个 INI 都是用户本机数据，均不能进入分发包。便携更新只替换程序管理的文件，因此会保留这两个 INI；新配置同时已加入 Git 忽略和发布排除检查。

## 页面与运行状态

工作流恢复 v1.9.16 的任务、参数、运行信息左右三栏，货运和客运仍是独立任务。点击名称查看参数，启用与拖动分别操作；运行时可查看其他任务，但不能修改本轮参数。四种货运模式始终可见，低频设置折叠，不恢复摘要与详情两套编辑器。

右侧通过标题栏的收起按钮压缩为紧凑状态条，仍可启停流程；展开后原日志和进度保留。默认在工作区宽度低于1120逻辑像素时自动收起，达到1200时自动展开。窄窗手动展开保持到回到宽窗；手动收起会记住选择。日志页签与进度页签共用右侧空间。

当前参数页与正在执行任务分别标明；城市重复访问、客运每个单程分别记录。子操作是观察信息，点击/调用返回不等于业务完成。未确认的结果不当成收益或成功；未知任务内百分比显示阶段与耗时。停止先等待执行端确认，之后才显示已停止。

冻结程序的 `--self-check` 额外检查切页、模式切换、任务排序、试算返回、折叠日志和停止状态。这些检查不派发游戏任务，不代表真实游戏运行验收。
