# User Guide

Aura_script_lsns is used from either the Resonance GUI or the local CLI.

Start here:

```powershell
.\scripts\run_cli.ps1 gui resonance
.\scripts\run_cli.ps1 tasks resonance_pc
```

The GUI is launched through the `gui resonance` command and executes
Windows-client tasks from `resonance_pc`. It provides a guided workflow, freight
and passenger configuration, battle dispatch, player data, run history and
settings.
