# 深潜规划与四视图集成

本次基于 v1.10.1 的 main 集成深潜规划、关卡内执行、目标识别和四视图扫描。原有单局、循环、布局扫描、数据采集及灵敏度探测入口继续保留；新增离线规划和关卡内自动运行入口。

## 运行边界

- 规划任务读取保存的布局，不进行游戏输入；关卡内执行任务需要用户主动启动。
- 扫描支持显式 `scan_route=four_views`，默认路线及各安全门保持源码定义，不因本次合并放宽识别或执行条件。
- 实体模型使用现有 CPU/auto 后端。`dml_worker` 是可选隔离进程，需要显式配置外部 Python、运行库和设备，CPU 完整包不内置该运行库。
- 模型、模型 metadata 和四视图几何均为运行资产，发布计划组装器会精确收集；训练输出、用户缓存和研究原图仍不进入包。
- `research/` 仅用于离线算法验证和显式研究工具，生产扫描不依赖研究模块。参考标注和图片须由使用者提供，缺失时在输入操作前失败。

## 验证含义

本次合并验证源码、任务注册、GUI 接线、离线样本、取消与资源释放，以及发布资产收集。测试中的模拟采集和历史裁图不代表真实游戏流程验收。旧七路线验收工具也不代表四视图验收；连续 20 次同版本真实准确性验收仍需独立执行和记录。

历史方案和实验记录保留原日期及适用条件；当前 DML 部署方式见 [隔离运行时说明](resonance-pc-deep-dive-dml-runtime.md)，研究工具输入要求见 [research README](../../research/README.md)。本次不修改版本号、不创建发布标签。
