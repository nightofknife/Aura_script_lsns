# 莫测漩涡独立分支

接入单局任务的 `vortex_dispatch` 阶段，不新增任务。

## 隔离边界

- 识别：`_deep_dive_vortex_vision.py`。
- 状态处理：`_deep_dive_vortex_flow.py`，会话键独立使用 `vortex_*`。
- 配置：`data/deep_dive_vortex/catalog.json`。
- 模板：`templates/deep_dive_vortex/`，为物理副本，不引用回生空洞模板目录。
- 调度：同一任务的截图入口按阶段选择识别器。漩涡阶段跳过回生空洞的选项检测；共享输入、截图、取消、节点预览和任务结束等基础能力。
- 后续新增漩涡效果只修改以上分支，不修改回生空洞模块和目录。

## 目录状态

62个事件配置、168个选项：85个允许且支持，19个被移动／行动回合／旋转规则排除，64个允许但暂未支持。其中29个无效果命令的结束选项统一优先。

支持：单纯回血／扣血／结束；直接获得尘埃；获得单个随机推力或骰子；扣血换单个奖励；随机强化一个推力；三选一；选择丢弃一个物品后继续已支持效果。

暂未支持：事件内战斗、下一组选项、单项布局、跨次遭遇版本、随机丢弃、多件／混合奖励、多目标强化、尘埃组合效果／扣除、物品溢出替换。未知效果默认未支持。包含一个未支持效果的组合选项整体为未支持。

## 选择与停止

先排除禁止和灰色选项。无代价结束事件优先级-10，直接回血0，其他已支持效果10，同级从上到下；未支持效果不参与有已支持候选时的竞争。即使属于跨次遭遇事件，空效果命令的直接结束选项也允许优先选择。只有没有任何可用的已支持选项时，才停止并保留截图。

坚守者固定按此策略选择“径直离开”。角色立绘式结束页使用公共 Deco_Title 装饰图标在结束位置的笔画蒙版识别；七个NPC事件共用此控件，不依赖红环、具体人物、名称或叙述。保留现有流程上下文和稳定检查，不修改回生空洞。

选项变蓝后再次点击主体；道具一张选唯一、两张选左、三张选中间；仅检查目标勾选，不读取数量。点击后的检查、两秒重试间隔、最多三次、30秒页面超时和180秒总时限沿用复制版本。若提交后选项组合改变，作为未支持的新分支停止，不把新页面当旧目标重试。

实际出现未知页面时等待至超时保存现场。没有为暂未支持的货币提示、子战斗或物品替换添加猜测点击。

## 直接获得尘埃

使用现有获得物品标题＋空白退出提示、公共结束位置图标识别直接尘埃奖励，无数量OCR。支持单一Reward命令、仅11400607尘埃奖励且正数范围有效的选项，金额不同共用Reward.Currency流程。尘埃和其他效果组合、扣除尘埃、事件跳转与跨次遭遇仍保持原限制。优先直接退出的策略不变。
