# 莫测漩涡独立分支

接入单局任务的 `vortex_dispatch` 阶段，不新增任务。

## 隔离边界

- 识别：`_deep_dive_vortex_vision.py`。
- 状态处理：`_deep_dive_vortex_flow.py`，会话键独立使用 `vortex_*`。
- 配置：`data/deep_dive_vortex/catalog.json`。
- 模板：`templates/deep_dive/deep_dive_vortex/`，为物理副本，不引用回生空洞模板目录。
- 调度：关卡内自动运行从桥接器读取漩涡选项、奖励卡和满包弹窗。截图继续识别节点入口、结果和收尾页面。单局随机游走使用原画面入口。
- 漩涡与回生空洞共用选项优先级，各自保留事件目录和页面处理流程。

## 目录状态

目录包含 62 个事件配置和 168 个选项。桥接模式可执行 96 个选项，其中 5 个触发子战斗。19 个选项因行动规则被排除，53 个效果分支暂未支持。

支持：单纯回血／扣血／结束；直接获得尘埃；获得单个随机推力或骰子；扣血换单个奖励；随机强化一个推力；三选一；选择丢弃一个物品后继续已支持效果。

关卡内自动运行接入了防御系统故障和地板塌陷的扣血领尘埃、求真者的随机骰子和推力、骑士的承诺领尘埃，以及狭路相逢的「以和为贵」。随机奖励复用现有领奖流程，并处理连续的领奖弹窗。

原型机选择「为啥要帮你啊？！」后先处理奖励，再核对下一组事件 ID。后续优先选扣血最少的「一动不动」。

已接入的子战斗包括战斗模拟系统、狭路相逢、防御系统故障、原型机和扭蛋机后段。进入编队后先核对该选项指定的关卡 ID，再复用常规编队、战斗结算和奖励处理。胜利返回后恢复漩涡与原移动事务。

其他未配置的子战斗、选项切换、跨次遭遇效果及组合奖励仍需各自确认。包含未知效果的选项保持停用。

## 选择与停止

先排除禁止、灰色及当前运行方式未适配的选项。顺序为免费且非战斗的收益、免费离开、付代价但无需战斗、战斗。同类消耗优先选代价较低的选项。没有可用的已支持选项时，停止并保留截图。

坚守者固定按此策略选择“径直离开”。角色立绘式结束页使用公共 Deco_Title 装饰图标在结束位置的笔画蒙版识别；七个NPC事件共用此控件，不依赖红环、具体人物、名称或叙述。保留现有流程上下文和稳定检查，不修改回生空洞。

关卡内自动运行按事件 ID 和选项 ID 匹配目录。桥接器确认目标仍可用且已选中后调用原生确认。每个面板只提交一次。单选道具一张选唯一、两张选第一张、三张选中间。页面超时为 30 秒，事件总时限为 180 秒。出现后续选项时，须匹配当前分支配置的后续事件 ID。

实际出现未知页面时等待至超时保存现场。直觉已满时复用奖励处理，丢弃新直觉后继续当前漩涡。

## 直接获得尘埃

使用获得物品标题和空白退出提示识别尘埃奖励，不读取尘埃数量。单独发放尘埃和目录中明确接入的组合效果共用奖励展示流程。
