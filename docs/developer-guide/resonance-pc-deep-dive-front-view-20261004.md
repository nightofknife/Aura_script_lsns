## 实机资源与关闭

主代理独占 WGC 和游戏输入；子代理仅运行经批准的短 CPU 离线检查。
本轮发现 EmbeddedGameRunner.close 清注册表本身不调用 TargetRuntimeService
的 Windows session.close。实验脚本已在清注册表前显式关闭自己持有的
adapter，并保存 capture_closed / session.closed / backend_session_released。
trial04、trial05 的关闭记录确认其 WGC 会话已关闭。

某些已结束辅助进程仍被进程枚举列出；直接读取 Windows 进程退出码，
trial01–05 的实际 Python 子进程均返回 0，而不是 STILL_ACTIVE=259。
这不能作为捕获关闭的替代证明，关闭以明确会话记录为准。尚未确定枚举
残留的原因，不能把它断言为 DLL 卸载故障。
