## 识别方法

入口为纯函数 `_raw_workshop_digits.read_fraction(image, region, style=...)`：

1. 输入 BGR uint8 图像，裁取已经定位好的完整人数区域；`style` 明确为 `list` 或 `selection`。本模块不负责定位名单标题或识别整个页面。
2. 浅底提取暗字；深底使用 RGB/BGR 三通道最大值提取亮字，让黄色分子、白色分母不会因灰度亮度差而错误粘连。随后单字符单独归一化对比度。
3. 用前景投影切分字符，保持字形宽高比例。缺字、明显截断和异常小组件直接返回未知；宽组件可以尝试局部切分，但不生成或匹配整组数字模板。
4. 对应字库内采用灰度 soft-Dice 字形分数，允许归一化网格 ±1 像素对齐；字形分数至少 0.75，第一与第二候选差至少 0.04。
5. 结果必须符合一到两位数字 `/` 一到两位数字；拒绝前导零、多个斜杠、容量为零、当前人数大于容量以及不同解释的近似并列结果。
6. 输出 `current`、`capacity`、`full`、最低字形分数、最低候选差和各字符结果。`full` 只由当前人数是否等于实际容量决定，不硬编码 6、7、15 等容量。未知返回 `None`，不伪造为 0 或满员。

这些字形分数不是房间导航的相关匹配分数，阈值不互相套用。接入经营流程时仍需要新截图、两帧确认和用户要求的点击成功／切页完成检查。
