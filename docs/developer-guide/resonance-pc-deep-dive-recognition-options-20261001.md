# 识海深潜：三个候选方案与实测边界

> 本文为选择方案前的研究报告。用户已选择方案1，生产接入、最新实测、未解决问题和暂停恢复步骤以[方案1暂停交接](resonance-pc-deep-dive-option1-handoff-20261001.md)为准；下文研究阶段的“尚未接入”与权重未版本化描述属于历史状态。

用户目标：单次识别不超过60秒，平均不超过50秒，正常约40秒；奇点、玩家、灵感最终所属格准确率稳定超过99%。允许自主研究、修改、测试和必要的游戏状态调整，最终由用户选择方案。

**目前没有方案同时完成上述全部验收。** 以下是继续开发的三个优先方案，不能把局部模型推理速度或一次成功当成整段达标。

## 1. 目标检测＋实时几何＋按需补格（推荐）

使用实体检测模型找玩家头部、奇点、灵感；当前帧图案校正姿态，比较六面全部54格的有限法向走廊，拒绝背面外伸实体被正面吸附的情况。目标位置由多个真实视角确认。先完成目标定位，普通格图案仅在规划或操作需要时补读；游戏动作确认后可以增加静态图案复用。

优点：保留已验证的几何、页面与输入事务；实体不再受单格裁片截断限制；可以直接减少最后几个普通格的重复扫描，开发风险较低。

缺点：需要修改规划器对未知普通格的处理，未确认的节点不得作为已知路径使用；目标位置已知不能冒充完整地图。仍依赖图案校正与遮挡处理，也没有稳定99%的独立验证。

实测：启用真实目标框规划的一次换面扫描，在31.806秒得到玩家U11、奇点D11、灵感F22/B12及六面已观察的中间结果，后续保存结果保持一致；结束时仍只有52/54格，整图59.484秒且失败。这是**目标定位阶段的中间检查点**，不含最后页面检查/报告排空，不是已接入规划器的完整方案或40秒验收成功。

实体模型与规则/几何融合的另一版本完整扫描为49.281秒。连同三次重复测试，完整成功3/4，包含失败的平均55.535秒，最大59.406秒；尚未达到平均要求。任务分发到结果返回另有开销，例如一份59.406秒扫描的调用耗时为61.424秒，不能宣称严格单次60秒已保证。

## 2. 图案与实体联合定位模型＋实时反馈扫描

直接在完整魔方区域定位所有图案和三类实体，再由几何关联格子、跨视角融合和选择缺失视角。用一次联合模型推理替换大部分逐格暖色形状匹配，保留实际姿态拟合、页面检查和不确定结果拒绝。

优点：加速识别与图案定位的空间最大；可以用实际图案中心修正偏移，减少逐格裁片失真；对浮在格子外的实体更合适。

缺点：需要更多不同棋盘、角度、特效、遮挡的独立标注，以及GPU支持；误框或误分类可能影响姿态和后续整图，仍需要几何验证。当前没有完成联合模型的完整实机验收。

已有的独立试验：实体模型完整ROI暖推理约10.6ms；图案定位模型约16.4ms。两者是不同试验管线的局部耗时，不能相加后直接当成联合模型或整段耗时。图案模型在手工接受的64个live02框里，以.25阈值正确63/64；另一个棋盘视频的63框全部正确。但95个额外预测经人工复核仍有4个三眼误判单眼、1个两个绿色图案被合框，3个裁断/HUD例外隔离。白色图案没有真实训练样本。现阶段不能认定99%稳定准确率。

## 3. 首次完整建图＋游戏规则增量维护＋局部视觉复核

首次建立地图。自己提交且实际确认的90度层旋转按游戏置换更新格子内容；明确的普通移动、灵感拾取按事务更新变化格。重新注册视角后，只验证必要目标和受影响的图案。敌方动作、换位面、漩涡、无法解释的事件或版本变化触发失效与全扫。

优点：重复识别量最少，对后续回合平均耗时最有利；收益主要来自逻辑而非硬件；已知游戏置换能利用之前可信的地图。

缺点：首次扫描的瓶颈仍存在；实现状态一致性、动作回执和失效规则比较复杂；漏掉副作用会传播旧地图错误。此方案只有研究原型与一致性验证，没有局部刷新整段耗时或99%验收结果。

实机证据：确认一次中间x层旋转后，重置视角随玩家变化。枚举两种旋转符号及24种整体重标记，仅使用图案选择映射，唯一最佳解释与47个已确认图案全部一致，独立于目标标签选择；该解释预测的四个目标位置与新扫描吻合。这支持利用明确动作与视角重注册，但仍是同一棋盘的有限验证。

候选地图必须保留`prediction_only`，不能将游戏规则推算直接当成新视觉证据或可执行地图。研究guard会把候选的`success/layout_complete`清为false；生产执行链尚未接入该增量方案。

## 实验取舍与已保留修改

- 四类格子CNN试验在两份未训练的保存会话上强制分类分别122/153、120/159正确，约79.7%/75.5%。普通六边形/眼图案误报灵感，灵感又常被当空格；虽然批量推理很快，本轮没有列入前三。扩大裁片也不能自动解决归属与遮挡。
- 自然roll角点路径有较短的几何覆盖预测，但第一版实机51/54、59.484秒。第二版保留中断路线和有限补扫后52/54、44.484秒主动阻塞；不是成功提速。仍为研究helper，未默认接入生产。
- 提高语义提交频率的三次实测只完整成功1/3，平均59.333秒；已回退该尝试。没有通过增加预算解决超时。
- 页面二值掩膜NCC、批量投影、同源裁片/关联复用、多面实际图案校正、明确源帧与地图版本等修改保留。精确页面ROI缓存只复用像素完全相同区域，四模块有界且线程隔离；236张完整页面逐字段零差异，中位48.35→44.59ms。
- 暖色图案仅在原形状拒绝时补充完整中央组件，模板与当前裁片同样归一化、保持.78/.055门槛；完整大紫环仅凭居中曲线空腔允许局部大小例外，没有整体放宽颜色数量上限。
- 流快照原先删掉了真实目标框等规划字段，导致实际遮挡包络没有被使用；已补传同源目标框、点和置信度并增加跨模块回归。
- 实体模型、便宜头部规则融合、当前帧姿态验证与54格竞争否决仍在研究注入中。没有默认启用尚未选择的模型、角点策略或增量地图。
