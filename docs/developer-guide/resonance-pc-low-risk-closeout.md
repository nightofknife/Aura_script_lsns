# PC 低风险去重收尾

本批完成卖货等待、buy_lot 归一化、校准商品 mask 生成和采购书无效参数清理。公共动作参数及任务入口不变，深潜及其共用依赖、框架、识别配置、模板和历史截图保持。

卖货 `SellSession.pause` 保留由调用方计算截止时间，委托已有 `sleep_before_deadline` 执行等待。单调时钟读取、每段最多 0.05 秒、循环中的 guard 和结束后的 guard 保持；没有新增时长转换。选品、提交、结算及卖货消费判断均未修改。

规划器与市场数据服务通过私有 `_buy_lot_normalization.py` 共享纯归一化。键裁剪、跳过无效行和空键、原有 int 转换、负数检查、碰撞覆盖及插入顺序保持。错误工厂保留两个服务各自的异常类型、代码、消息和因果链；schema 检查、规划器缓存身份、市场数据读取和 source/default_lot 元数据仍由调用方处理。

黑月校准生成器将共享 96×96 mask 的创建、绘制和保存封装为一次操作，在首个有效商品图保存后调用。原商品遍历、校验、选中态跳过及写入顺序保持；完整 140 商品每次只写一次 mask。图像配方、商品阈值、混淆商品计算、摘要和来源信息保持，不生成第二份 mask 或旧路径副本。

采购书 `_click_template` 只接受模板及识别参数。无效 fallback 参数、禁用回退的诊断字段、三个独占坐标常量和取消按钮的无效坐标实参均已移除，无旧名称转发。实际数量加一坐标保留。确认前重新匹配、未知时停止、取消后不继续输入、错误清理及一次确认消费保持。

验证包括新旧卖货等待事件轨迹、两个 buy_lot 调用方的输出/异常/顺序对照、完整生成器输出字节对照，以及采购书公开动作的偏移、缺图、取消、确认前重新识别和一次消费回归。所有检查从仓库根目录运行，临时输出限制在仓库 `.pytest_tmp` 下；离线结果不代表实机验收。
