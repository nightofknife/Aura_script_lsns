# Resonance PC v1.8.17：海角城投资失败阻断后续卖货

> 状态：问题分析占位，等待后续实现。
>
> 本文档记录用户日志中的已确认事实、源码调用顺序和待定修复边界。本 PR 不包含业务代码修改，也不表示问题已经修复。

## 问题摘要

用户反馈跑商运输到站后货物没有成功卖出。日志中第一轮正式跑商能够完整解释这一现象：任务从修格里城运输到海角城，到站后先触发自动蜃息岛投资；投资指标稳定读取失败并向上抛出异常，整条跑商路线随即终止，因此海角城交易和最终卖货尚未执行。

这次故障不是“海角城卖出按钮未点击”，而是一个到站后置业务在必需的卖货流程之前失败，并阻断了后续主流程。

## 投资指标读取详情

日志中的异常详情为：

```text
code=investment_metric_unreadable
message=unable to read all island investment metrics consistently
values={}
ocr_history={
  share_percent: [{texts: ["1.5%", "分成比例"], value: 1.5}],
  tax_reduction_percent: [{texts: ["-0.2%", "纳税减少比率"], value: -0.2}],
  ticket_price: [{texts: ["60", "票价提升"], value: 60}]
}
```

三个指标都曾各自读取出一次合法值，但当前实现要求同一指标最后两次有效值完全一致，才会写入 `stable`：

```python
valid_values = [item["value"] for item in histories[name] if item["value"] is not None]
if len(valid_values) >= 2 and valid_values[-1] == valid_values[-2]:
    stable[name] = valid_values[-1]
```

本次每个指标只有一个有效样本，因而 `stable` 最终仍为空。这里需要进一步确认单轮三个 OCR 调用是否耗尽了整体超时，以及是否应改为每项独立时间预算或批量截图读取；当前 PR 只记录问题，不预先确定实现。

## 源码调用顺序

`_execute_trade_leg` 当前顺序为：

```text
出发城市交易
  -> 跨城运输并等待到站
  -> 到达海角城后执行自动蜃息岛投资
  -> 投资完成后才返回当前路段结果
  -> 下一路段交易或终点最终卖货
```

当 `_execute_cape_island_investment_after_arrival` 抛出异常时，`_execute_trade_leg` 会记录投资失败事件后直接 `raise`。因此路线不会继续，终点卖货也不会发生。

- `plans/resonance_pc/src/actions/cape_island_investment_pc_actions.py:238-273`
- `plans/resonance_pc/src/actions/cape_island_investment_pc_actions.py:543-550`

## 已确认与未确认的边界

### 已确认

- 修格里城到海角城的运输已完成。
- 自动蜃息岛投资在到站后、后续卖货前触发。
- 投资指标读取失败是本轮任务的直接异常。
- 该异常向上传播并结束整条跑商路线。
- 因此用户看到货物未卖出，是主流程在卖货前已被投资子流程阻断的直接结果。

### 尚未确认

- 单轮指标读取为什么只留下每项一个有效样本，需要结合 OCR 调用耗时或现场截图继续验证。
- 自动投资失败后应当“降级跳过并继续卖货”，还是根据用户配置进入严格失败模式，需要在实现前明确产品语义。
- 投资失败后的可靠界面恢复路径尚未设计；不能只吞掉异常后假设仍在城市主页。

## 后续修复需要覆盖的边界

1. 明确到站后主业务与可选业务优先级：运输货物的结算/卖货不应被可选投资无条件阻断。
2. 自动投资失败时必须恢复到可确认的城市主页或城市面板，再继续交易；不得只改成捕获异常后盲目执行下一步。
3. 调整指标稳定读取的时间预算和采样方式，保证三项指标都实际获得足够的稳定样本。
4. 将投资结果区分为 `completed`、`skipped`、`recoverable_failure` 和 `fatal_failure`，避免仅靠异常决定整条跑商路线命运。
5. 日志中保留每项指标的采样次数、单次耗时、最终页面状态及恢复结果。

## 建议验收场景

- 自动投资关闭时，到达海角城后正常进入卖货。
- 自动投资成功时，投资完成并恢复到正确页面，然后继续卖货。
- 投资页面未出现时，按确定的降级策略恢复并继续或明确失败。
- 三项指标只有单次有效样本时，不得长时间无信息卡住；日志必须说明采样次数和耗时。
- 投资 OCR 失败时，不得在未知页面状态下继续点击交易入口。
- 无论投资结果如何，只能在确认页面状态后进入后续卖货步骤。
