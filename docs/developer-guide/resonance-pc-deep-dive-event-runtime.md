## 选择策略

直接回血优先级0；其他允许效果10；结束事件20；同级从上到下。灰色、禁止选项排除，不读血量。数值不同但执行类别、状态和优先级一致的版本不互相竞争。默认屏蔽 Action、StepNum、增加SpinNum；未支持的 Event／Level 命令不进入选择。

## 点击闭环

每次点击记录 pending 类型、目标、次数与时间。稳定两次观察后核对结果：选项变蓝、目标卡勾选、页面退出或返回魔方。旧画面保持不变时等待至少2秒再重试，同一步最多3次。无可识别后续页面30秒停止；整段事件180秒停止，保存现有诊断截图。无效帧重置稳定计数；标题蒙版匹配出现非有限值视为不确定。

结束布局同时要求蒙版标题和居中红环的粗布局证据。入口动画也可能居中，因此未看到实际选项／奖励页前禁止将其作为结束叙述跳过。不识别八音石名称；结束等待稳定后点空白，若只补全文字则下一次观察仍确认同页后有限重试。

结果展示可以接下一次选择、展示或结束页；重复结果页采取间隔受限的关闭重试。返回魔方需要玩家行动中和行动步骤两个固定区域特征，不用移动／旋转次数数字作为页面判断。确认返回时只提交一次 pending_move，回合计数仍由旋转完成推进。
