# 识海深潜第一位面回合与灵感收益计算

日期：2026-09-30。本文回答第一位面初始状态下，不追求灵感、要求全部灵感，以及限制六回合时的到达回合数和灵感收益。结果来自规则模型的状态穷举和动态规划，属于模型结果，不是实机统计。规则来源见[移动规划设计](resonance-pc-deep-dive-movement-planning.md)。

主要结论：只追奇点的最短平均到达时间约 2.286 回合，但没有有限最坏保证。六回合灵感收益优先策略平均实际拾取约 1.953 枚、到达概率约 96.72%；若严格优先最大化六回合到达概率，平均灵感降至约 0.577 枚。随机行动使成功率与灵感收益存在取舍。

## 统计口径与模型假设

用户确认采用三阶魔方，初始玩家在顶面中心、奇点在底面中心，两枚灵感，每回合玩家与奇点各移动一次、层旋转一次。用户确认奇点只走同面正交相邻格，同面追击时从缩短曼哈顿距离的候选中等概率选择；其他情况下从全部合法邻格等概率选择，四种合法旋转等概率选择。玩家观察当前完整状态，允许先移动后旋转或先旋转后移动。

两枚灵感初始位置按 52 个非玩家、非奇点格中等概率选择两个不同格计算，共 1326 种布局。客户端配置中这 52 格使用同一个常规格包，灵感生成限定普通或精英战斗节点；实际服务器空间抽样代码不在客户端。因此 1326 种组合等概率是可交换空间生成规则下的合理推断，尚未通过实机新局分布确认。

以下计算忽略节点事件、道具、骰子改变回合或动作额度的效果，不计算战斗胜负和 Boss 战额外奖励。只计地图原有两枚灵感。奇点吞入的灵感从自由集合中移除，不记为玩家所得；不假设战斗会返还吞入物。视角识别和点击均按准确且生效处理。

玩家或奇点普通移动产生相遇即算到达。奇点移动碰到玩家在旋转前终止，最后一回合也先执行奇点行动再判断耗尽。到达发生于第几轮，就记几回合，不要求该轮剩余操作继续完成。

“理论最多”指对所有合法随机分支的最坏回合；“平均”指明确策略下随机分支的期望。对无法满足目标的局，目标完成时间为无穷；将其排除后计算的是成功局条件平均，必须单独标明。

## 不考虑灵感的最快追击

完整枚举 2862 个玩家与奇点的不同格有序位置组合及全部合法动作，按 24 种整体旋转压缩为 120 个等价类。

- 最快可能到达：2 回合。
- 最短平均到达：1719/752，约 2.2859042553 回合。
- 理论最多回合：无有限上限。存在合法随机分支持续拖延到达。

最快平均策略的到达分布如下。这是一条针对最短期望时间的策略，不等同于每个固定截止回合下的最佳策略。

| 截止回合 | 已到达奇点的累计概率 |
| --- | ---: |
| 1 | 0% |
| 2 | 75% |
| 3 | 96.875% |
| 4 | 99.609375% |
| 5 | 99.934896% |
| 6 | 99.991862% |

若专门最大化六回合内到达概率，最优值为 18431/18432，约 99.9945746528%。虽然非常接近 100%，仍存在 1/18432 的超时概率。

期望值由有理数线性方程求解，并逐一检查全部状态、全部动作的 Bellman 最优性不等式。有限最坏保证集合在第二轮后固定，初始位置属于剩余 22 类：其每个玩家动作均存在一个正概率奇点结果继续留在该集合，因此不存在有限回合保证。这不是从少量模拟中遇到长局作出的推断。

## 要求收齐两枚灵感再到达

理论最多回合仍无有限上限。若把所有初始局、所有随机结果都纳入平均，而且目标必须收齐两枚，完成时间的总体期望是无穷，因为存在永久无法满足该目标的局。

一个可明确证明的反例是，两枚灵感在底面中心奇点周围、成直角的两个邻格上，共四种布局。玩家首回合的任何合法操作都有至少四分之一概率让奇点立即吞掉灵感。最优操作能让其他四分之三概率进入最终可收齐并到达的状态。

完整状态图的安全集合和几乎必然可达集合证明：其余 1322 种初始布局在无限回合下可以以概率一最终收齐并到达，这四种布局的最优成功率各为四分之三。因此无限回合下总体最高成功率恰为 1325/1326，约 99.9245852187%。这些失败分支不能通过增加回合数恢复已经被吞掉的地图灵感。

在有限预算内，以“收齐两枚并到达的概率最大”为目标求解，结果为：

| --- | ---: |
| 2 | 0.942685% |
| 3 | 13.265146% |
| 4 | 42.660733% |
| 5 | 75.107130% |
| 6 | 92.599226% |
| 7 | 98.332955% |

每一行分别针对该截止回合求最优策略，不能把各行相减当成同一策略的回合分布。六回合策略中，成功收齐并到达的局平均用 4.696489 回合，成功局最晚第六回合到达；失败局没有混入这个条件平均。增加到七、八回合能提高成功率，但无法消除前述吞灵感失败分支。

## 六回合内的平均灵感收益

对三个明确目标分别求解，均枚举所有奇点随机结果，并实时移除其吞入的灵感。

| 策略目标 | 六回合到达概率 | 收齐两枚且到达概率 | 每局平均实际拾取 | 平均拾取中被计入按期成功的数量 |
| --- | ---: | ---: | ---: | ---: |
| 六回合到达概率最大，同概率再多拾取 | 99.994575% | 5.399062% | 0.577458 | 0.577377 |
| 收齐两枚并到达概率最大 | 95.876309% | 92.599226% | 1.965090 | 1.883213 |
| 按期成功时的灵感收益期望最大 | 96.720850% | 92.037572% | 1.952609 | 1.887571 |

“实际拾取”包括最终超时局在截止前已经取得的灵感。“按期成功的数量”只计六回合内到达奇点的局，超时局对这一联合目标记零；这是一种规划评分，不表示游戏必然没收超时局已经领取的奖励。

第三种策略最大化按期到达时的灵感收益期望，适合比较“多拿灵感同时完成追击”的收益。它的具体分布为：

| 六回合结束或提前相遇时已经拾取的数量 | 概率 |
| --- | ---: |
| 0 枚 | 0.001331% |
| 1 枚 | 4.736433% |
| 2 枚 | 95.262237% |

上表“拿到两枚”不代表已经到达奇点；两枚加到达的联合概率是 92.037572%。所有局的实际拾取平均 1.952609 枚，按期成功局的条件平均约 1.951566 枚。

奇点吞灵感已真实参与状态转移，而非在总收益最后扣一个常数。第三种策略每局平均被奇点吞入 0.009794 枚；余下约 0.037597 枚在截止或提前相遇时尚未拾取或吞入。三个数量相加为初始两枚。个别初始布局的平均实际拾取在约 1.303055 至 2 枚之间，因此均匀初始布局均值不应被解释成每一局都能拿到同样数量。

## 计算方法与复核

含灵感的状态记录玩家、奇点、自由灵感位置，以及已经确认拾取的数量。格子层旋转同时置换所有角色和灵感；角色普通移动分别执行拾取或吞入。已经吞入的灵感永远不会通过本模型的层旋转变回自由灵感。

共建立 164453 个整体旋转等价状态。每个回合先计算奇点阶段的加权结果，再计算玩家所有两种操作顺序的最优选择。记忆化的有限回合动态规划给出各初始布局的到达概率、拾取期望、吞入期望和成功时间矩，再按 1326 种等概率布局汇总。

数字验证包含：

- 含灵感模型在零灵感状态下的六回合到达概率，独立复算为 18431/18432，与只追击的有理数计算一致。
- 所有旋转是双射，正反旋转可逆，所有奇点分支概率和为一，状态索引完整。
- 三种策略各做十万条独立随机轨迹复核。复核程序重新实现移动、旋转与拾取计数，只使用动态规划选出的策略；概率和收益与精确模型在抽样误差内一致。
- 检查拾取量、吞入量和未处理量的守恒，以及零、一、两枚拾取概率的总和。

分析代码、精确动态规划结果、状态图证书和随机轨迹复核结果原保存在仓库本地 .analysis_tmp/deep_dive_planning_20260930/stats_full、stats_bounds、stats_spawn。交接时将源码与 JSON/文本结果复制到 [evidence/deep-dive-20260930/statistics](evidence/deep-dive-20260930/README.md)，大型 .npz 缓存未推送；均不是游戏运行时依赖。这些验证确认的是明确规则模型内部的计算；真实新局的生成分布、客户端层转映射、识别准确率和事件副作用仍需单独实机确认。

## 对规划设计的修正

随机旋转下，严格“六回合所有分支必到达”从第一位面初始状态就没有可行解。保证模式应返回无保证方案，不能改写成近似成功。

实际使用的概率模式应明确目标和风险：可以优先六回合到达概率，也可以优先收齐灵感概率或按期成功的灵感收益。三者有不同最优策略。设置允许的超时概率后，还可继续计算对应收益约束的策略；本次没有擅自选择一个风险阈值作为用户要求。
