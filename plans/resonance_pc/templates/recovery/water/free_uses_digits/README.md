# 气泡水免材料次数：0–6 数字模板

这批素材只用于恢复疲劳页气泡水信息提示框中的黄色次数数字，
不与仓库数量数字模板混用。现已接入用户信息任务，替换气泡水次数 OCR，
不影响货舱、澄明度、疲劳及其他功能的 OCR。

## 文件与裁剪

- `0.png` 至 `6.png`：RGB 原始字形，统一 **32×48 px**，不缩放字形。
- `0_mask.png` 至 `6_mask.png`：对应的单通道 8-bit mask，同为 **32×48 px**。
- 字形水平居中，黄色笔画底边统一放在模板 y=43（零基坐标），下方保留 4 px。
- mask 中 255 表示参与匹配，0 表示忽略。模板中被忽略的像素置黑。
- mask 包含黄色笔画、抗锯齿边缘及约 1 px 轮廓保护带。
  面板背景、附近文字、斜杠和右侧上限数字均不进入有效 mask。
  不使用纯笔画 mask，是为了避免 `1` 匹配到 `4` 的竖笔画。

背景分割只在制作这批模板时使用；运行时应对原始截图进行带 mask 匹配，
不对截图做二值化或颜色阈值处理。

## 框架调用约定

使用框架 `vision.find_templates_batch`，按 0–6 显式构造模板和 mask 路径列表：

- `template_images`: `0.png` ... `6.png`
- `mask_images`: `0_mask.png` ... `6_mask.png`
- `use_grayscale=False`：源截图是 RGB ndarray；模板路径由框架处理颜色通道。
- `match_method=cv2.TM_SQDIFF_NORMED`
- `preprocess="none"`

源区域只包含待识别的单个数字，不把左侧剩余次数和右侧上限一起搜索。
任务在 1280×720 客户区截取 `(937,221,88,52)` 的原始 RGB 数字带；
左侧剩余次数使用带内 `(0,0,36,52)`，右侧上限使用 `(40,0,48,52)`。
右侧 ROI 额外覆盖左侧显示窄数字 `1` 时造成的水平位移。两侧同帧读取，
分别使用 0–6 模板，不把上限写死为 6。范围外数字不受支持。
不能遇到第一个超过阈值的模板就返回：应比较全部七个候选，取最高分并检查领先差。
框架的 SQDIFF_NORMED 置信度为 `1 - 原始差异值`，越大越好。

当前任务阈值：最高分至少 **0.95**，与第二名的差至少 **0.04**。
低分、分数不有限或差距不足时报告无法确定，不默认返回 0。
无法可靠识别时在 3 秒内重试；仍失败则沿用任务失败、不落盘的行为，不回退 OCR。
这些阈值经过小样本离线校准，不代表所有实际场景已经验收。
