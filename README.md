# Aura 雷索纳斯自动化助手

Aura 是一款面向 Windows 版《雷索纳斯》的桌面自动化工具，提供跑商、货运附加客运和战斗调度功能。

程序通过识别游戏画面并操作鼠标键盘完成任务。发布包已经包含运行环境，普通用户无需安装 Python。

> 本项目为非官方工具，与《雷索纳斯》官方无关。游戏更新可能导致画面识别或操作流程暂时失效，请根据自己的情况使用。

## 主要功能

### 自动跑商

- 自动刷新市场行情并计算完整跑商路线。
- 自动完成卖货、买货、砍价、抬价、城市移动和终点清仓。
- 可设置起始城市、参与规划城市、疲劳预算、货舱容量和进货书数量。
- 支持城市声望、商品解锁情况和贸易等级设置。
- 支持按需使用疲劳药。
- 支持到达海角城后自动进行蜃息岛投资。
- 可以只计算方案，不操作游戏；确认路线后再开始执行。

### 货运附加客运

- 不定线路货运可按实际座位数和传单目标，沿货运路线自动揽客、派发和结算。
- 附加客运不改变货运路线与疲劳预算，预计客运收入与货运利润分开显示。

### 战斗调度

- 可组合多项作战任务并按顺序执行。
- 支持协同终端、铁安局、区域作战中心、行动汇总和构析勘探等内容。
- 可设置任务类型、城市或关卡、难度、队伍和抓捕次数等参数。
- 支持执行前校验任务单。
- 可选择普通失败后是否停止后续任务。

## 下载

前往 [最新正式版下载页面](https://github.com/nightofknife/Aura_script_lsns/releases/latest)，根据电脑情况选择压缩包。

| 版本 | 适合人群 | 文件名 |
| --- | --- | --- |
| CPU 版 | 推荐大多数用户使用，兼容性最好 | `AuraResonance-版本号-win-x64-cpu.zip` |
| GPU 版 | 希望使用 NVIDIA 显卡加速画面识别的用户 | `AuraResonance-版本号-win-x64-gpu.zip` |
| CUDA 13 扩展包 | GPU 版无法使用本机 CUDA，或需要随包运行库时使用 | `AuraResonance-版本号-nvidia-cu13-overlay.zip` |

不确定选哪个版本时，直接下载 **CPU 版**。

使用 CUDA 13 扩展包时，先完整解压 GPU 版，再把扩展包解压到 **GPU 版目录所在的父目录**，允许合并同名的 `AuraResonance-版本号-win-x64-gpu` 顶层目录。扩展包和 GPU 主包都带有这个同名顶层目录；不要把整个扩展包直接解压进已经存在的 GPU 版目录，否则可能形成重复嵌套目录。

## 快速开始

1. 下载所需版本，并把压缩包完整解压到一个独立文件夹。
2. 启动《雷索纳斯》PC 客户端并登录游戏。
3. 建议把游戏画面设置为 `1280 × 720`，执行期间不要改变窗口尺寸或显示缩放。
4. 尽量回到城市主界面，再双击解压目录中的 `AuraResonanceGui.exe`。
5. 点击顶部“刷新目标”，确认右上角显示游戏窗口标题。
6. 点击 GUI 顶部的 **“？”** 打开内置使用教程，按步骤配置任务；教程可离线查看，也可按 `F1` 打开。
7. 在“工作流程”中只勾选需要执行的任务，填写参数，再点击“运行流程”。

请勿只把 `AuraResonanceGui.exe` 单独复制出来运行。程序需要同目录下的 `runtime`、`plans` 和 `models` 等文件。

## 页面使用

### 跑商

1. 在“工作流程”点击“货运”，填写疲劳预算、货舱容量和用书额度。
2. 选择参与规划的城市，按账号情况设置声望与税率、商品解锁。
3. 需要先看方案时，点击“打开货运试算”，填写独立试算参数及“试算当前城市”，再点击“计算方案”。此操作不会控制游戏。
4. 试算参数与正式货运参数分别保存。返回“工作流程”核对货运参数，勾选货运，再点击“运行流程”。正式运行会重新识别游戏当前城市。

### 货运附加客运

1. 在“货运”参数中选择不定线路，开启“附加客运”，填写实际座位数和传单目标。
2. 附加客运沿本次货运路线运行，不需要另选 A/B 端点或设置单程数。
3. 如果取消时存在未结清乘客，请按界面提示人工处理当前目的地，勿重复揽客。

### 战斗

1. 在“工作流程”点击“自动战斗”，选择要编辑的星期，再选择关卡和参数。
2. 点击“加入当天安排”，可调整任务顺序；构析勘探在普通关卡后执行。
3. 勾选自动战斗，点击“运行流程”。切换星期只用于编辑；实际执行自动战斗在后台开始时对应游戏日的安排，国服每天 05:00 换日。
4. 普通关卡优先扫荡，无法扫荡时再实战。停止时点击“停止”，等待作战收尾完成。

GUI 顶部的“？”提供离线使用教程与功能 Wiki。除了快速上手，还按功能详细解释参数作用、预算范围、资源消耗及选项联动，包含操作实例和排障说明。可用分类目录、关键词搜索、页内目录和站内链接查阅，也可直接打开对应配置页面。

## 运行注意事项

- 自动化使用真实鼠标和键盘输入，任务运行时不要同时操作鼠标键盘。
- 程序可能会自动把游戏窗口切换到前台，这是正常现象。
- 请保持游戏客户端运行，不要在任务过程中关闭游戏或调整分辨率。
- 网络异常会影响市场行情刷新和路线计算。
- 游戏更新、界面活动或临时弹窗可能打断自动化。遇到异常时先停止任务，处理弹窗并回到城市主界面后再试。
- 正常情况下无需管理员权限；如果游戏以管理员身份运行，自动化程序也可能需要使用相同权限启动。
